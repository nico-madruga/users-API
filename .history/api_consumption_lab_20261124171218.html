Your task: retrieve users from an API, render them, and retrieve a user's posts when requested.

SECOND REQUEST

User posts

    Your mission

    1. Make a GET request to https://jsonplaceholder.typicode.com/users.
    2. Check response.ok before parsing the response.
    3. Parse the response as JSON and save the result in a variable.
    4. Render one card per user inside #usersContainer.
    5. Make the search input filter the users already loaded (no new API request needed).
    6. When a card's button is clicked, request that user's posts from https://jsonplaceholder.typicode.com/posts?userId=USER_ID.
    7. Show loading, empty, and error states in the page.

    Rule: keep API requests separate from DOM-rendering functions. Don't put all your code inside the click event.
